## How to reproduce

```bash
ssh -i ~/.ssh/mac_mini_austin brock-mini-mac@[REDACTED-IP]
cd ~/scrooge-aggregator-test

# Step 1: Sweep (24 cells × 9s each = ~4 min on 8 cores)
python3 v5_aggregator_synth.py

# Step 2: Validate the kept candidates
python3 v5_aggregator_kept_recheck.py

# Step 3: Redundancy test on remaining factors
python3 v5_aggregator_redundant_recheck.py

# Step 4: Per-cell breakdown
python3 v5_aggregator_percell.py
```

Outputs land in the same `/Volumes/Alien Device/scrooge-research/v5_aggregator_test_2026-06-18/` directory (unless you change the OUT_DIR constant in each script).
